# 自建教程交付示例

打开 [报告](report.md) 或 [6 秒合成视频](tutorial.mkv)。本目录展示部署后用户的 agent 产生的可读交付，包含输入后取消、重新应用和运行报错。

视频由本项目的 `scripts/tests/make_gui_fixture.py` 生成，图像在审阅时实际展示后登记。报告使用当前 `export` 生成，增加了本段来源说明，并将仅保存在开发目录的机器账本链接改为说明文字。视频、报告和九张证据图均可随仓库读取，不需要原开发机器的路径。

这是完整的交付样式示例，保留一个未解决问题和未完成的审阅状态：它没有把界面显示的预期输出路径当作已生成的文件，也没有把编辑器中的成功字符串当作运行成功。

若要让自己的 agent 试用，提供本目录的 `tutorial.mkv` 并调用 `video-operation-review`，使用新的审阅目录。不要把示例报告里的观察当作本轮已完成的看图记录。

固定候选另附 [本轮原图复核表](recheck.json)：取消20后保留1、应用5后显示5、源码SUCCESS与错误结果分开。这是9次实际图片查看形成的内部一致性记录，不是独立人工标准答案，不用于计算语义准确率。
