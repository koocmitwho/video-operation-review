# 公开试用包：两行文本的正则替换

这是 `case-vscode-02` 的可复用试用材料，用于记录参与者能否依据分配的材料，在 VS Code 网页版完成一次正则替换。它不要求保存文件。

**本目录是发布时整理的 portable revision（可迁移修订版）**：修正材料之间的相对路径，删除与某个用户或对话有关的措辞。历史独立代理试用记录的任务阶段 21 秒、准备阶段 96 秒，使用的是当时原材料的字节；本公开修订版没有重新完成参与者试用。这些阶段历时不包括停止后的取证、记录、清理与核验，不能证明总体省时或真人可靠性。

案例结果、历史证据边界和被测版本见[案例说明](../README.md)；来源与许可见[第三方声明](../THIRD_PARTY_NOTICES.md)。本包没有真人试用结果。

## 组织者入口

1. 先阅读[组织者检查表](organizer/checklist.md)。为每位参与者复制一份空白[结果表](participant/result-form.md)。
2. 如需对照，将未见过材料的人分到原视频组或报告组，记录分配方式。同一人只做本任务一次，不以先看视频、再用报告的方式交叉比较。只有一人时可以记录个案，不设假对照。
3. 准备阶段只提供 `participant/preparation.md`、`participant/initial.txt`、`participant/result-form.md`。这些文件应放在同一文件夹。
4. 共同准备完成后，开始计时并首次发放对应任务材料：报告组收到 `participant/instructions.md`；原视频组收到核验过的原视频及其来源许可说明，不收到操作说明。
5. 第一次自报完成、无法继续或放弃时停止计时，先保留实际文本和时刻，再按检查表核验。补做成功另记，不覆盖第一次结果。

**不要把整个目录、组织者答案、历史结果或案例报告发给尚未开始的参与者。** 新上下文代理只收到明确分配的文件；真人与代理结果分别记录。先见过素材、操作说明、答案或同一任务的人仍可做可用性试用，但须标为已暴露，不能混入未暴露对照。

## 原视频组准备

安装包不包含第三方视频。组织者从上一级 [sources.json](../sources.json) 找到 `case-vscode-02`，按固定下载 URL 获取原始素材，核对 SHA-256 后再使用。不要重编码、用演示重录代替原片，或以视频标称时长代替参与者实际观看时间。分发素材时保留[来源与许可](../THIRD_PARTY_NOTICES.md)。

原片只有 2.66 秒，片头查找与替换参数已经存在；报告额外说明了准备路线。因此对照只能比较这两份具体材料，不足以证明纯粹文字对视频或整个 skill 的优势。

## 时间与结果

准备、正式任务、停止后取证与记录、核验分别计时。正式任务从首次接触分配材料开始，包含阅读、观看、思考、操作与求助；主动操作、被动等待和无关中断能可靠区分时再单列，未测就写“未测”。不能用总时间凭空倒推出各项，也不能重复相加。

不预填完成、求助次数、用时或核验结果。保留失败、放弃、求助和材料暴露记录；单次代理成功不替代真人结果，小样本不发布泛化准确率或节省比例。
