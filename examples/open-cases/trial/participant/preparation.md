# 参与者准备说明

## 任务

在 VS Code 网页版的新建纯文本页中，依据组织者分配的材料，完成片段演示的那一次正则替换。不要直接输入或粘贴猜测的最终答案。完成后保留编辑区内容，告诉组织者“我完成了”；本任务不要求保存文件。

## 开始前

1. 在同目录的[结果表](result-form.md)填写编号，以及是否见过本素材、相关报告、答案或同一任务。已经看过也可以试用，须如实记录。
2. 记录操作系统、浏览器名称和实际版本、VS Code 网页版可取得的版本或标识、界面语言。无法取得的项目填“未记录”，不要猜。只记测试环境，不记录账户、设备名称或浏览器会话标识。
3. 打开 [VS Code 网页版](https://vscode.dev/?vscode-lang=zh-cn)，使用一个新建、未保存的纯文本页。可从应用程序菜单选择“文件 → 新建文本文件”。不用登录，也不需要打开现有文件。
4. 把同目录的[初始文本](initial.txt)完整粘贴到该页。两行没有前导缩进，查找替换面板先保持关闭。准备工作到此为止，先不要打开分配的任务材料。
5. 组织者确认页面已可操作、初始文本已就位。共同准备的用时单独记录。材料按 Windows 默认键位编写，其他系统应记录差异。

## 计时

开始：组织者说开始，并首次显示分配的操作说明或播放原视频；从首次接触任务材料起计时，阅读和思考也计入。

停止：第一次明确说“完成”，或明确表示无法继续、放弃时停止计时。保留该时刻的实际内容，不先对照答案或修正。停止后复制文本、截图、填写记录及清理的时间另记。

如果停止后发现错误，先保留第一次结果；需要继续尝试时，另记补充尝试及其用时，不覆盖第一次。

## 过程中

可以反复看所分配的材料、暂停视频、回放、求助或指出卡点。报告组若转看原视频，或任一组用了其他说明、搜索、AI 帮助，都如实记为额外帮助及发生时刻，仍保留该次记录。

不要提前看另一组材料或组织者答案。网页加载、网络卡顿等被动等待单独记；阅读、观察、思考、点击、输入或交流求助记为主动用时。若不能可靠拆分，填“未测”，不要估造。

## 结束后

把编辑区的实际文本原样复制到结果表的“实际结果”栏，也可留一张结果截图。由组织者核对，参与者自报完成和核验完成分别填写。不要把组织者提供的答案当成自己的实际输出。
