# 分层审阅验收与实施计划

**Goal:** 默认按完整时间线粗审、操作单元精审和风险抽查执行；保留逐 RGB 状态严格模式。

**Architecture:** 复用原始 PTS、流式解码、精确哈希、SQLite 与证据库。新增 `vor_layers.py` 管理可回查的分段建议、人工区间、抽查和快照；`vor_language.py` 复用 FFmpeg 读取字幕并接收有时间基准的转写 JSON。宿主原生视觉负责语义判断，脚本不宣称识别真实操作总数。

**Tech Stack:** Python 3.10+、NumPy、Pillow、SQLite、FFmpeg/ffprobe；无默认 ASR 模型下载、外部收费服务或新增全局安装。

**Spec:** 全帧索引、区间粗审、操作精审、遗漏抽查及语言对齐的验收契约。

## 边界与决策

沿用全帧低语义成本索引；分段参考界面级变化、局部编辑簇、稳定段和短暂状态，时间窗口仅作最大上下文范围。固定间隔抽图和降低阈值不能代替语义粗审。自动建议保持未审阅；人工可以合并/拆分，必须保留原始帧区间、原因、代表证据、未精审范围。近似合并不改写精确重复身份。

旧库增量迁移保留步骤、查看、逐状态说明和复核；旧库沿用严格模式，新选择默认 layered，显式 coverage/strict 维持回归基线。操作审计复用前后状态和确认/结果检查。抽查绑定区间快照；发现异常需展开对应窗口，旧复核随内容变动失效。

## 先失败、再实现的案例

| 验收案例 | 可观察条件 |
|---|---|
| 等待、移动鼠标、闪烁 | 所有帧仍有索引与状态映射；建议代表少于状态数；不自动增加粗审、精审或视觉计数 |
| 单帧菜单、微小参数编辑 | 原帧/局部变化可查，存在风险提示/抽查机会；语义结论由实际看图提供 |
| 覆盖孔洞与重叠 | 区间未覆盖/重复覆盖明确报错，无法靠大区间或拼图生成声明完成 |
| 粗审与精审 | 粗审完整不等于全部精审；context 区间允许未精审，操作区间需要角色证据和步骤 |
| 取消与重输 | 临时值 0.20 不得写为最终值；确认后 0.02 与步骤 after 状态一致 |
| 跨步文件交接 | 同一 file 状态键的输出/下一步输入不一致时报告跳变 |
| 抽查缺失、过期、发现异常 | 未抽查不能通过；合并内容改动使抽查失效；异常入队局部严格展开，不能只更新标签消警 |
| 原图、裁剪、拼图去重 | 同源帧反复查看仅一个源帧；拼图只证明概览粒度，不能充当原尺寸数值精审 |
| VFR、非零起点 | 所有映射使用索引 PTS，不用平均 FPS；无时间戳保持未知 |
| SRT/VTT/内嵌文本字幕 | 保留原文、语种、来源、偏移；按原始 PTS 对齐；重叠不静默删除 |
| 中英混合、原文与翻译 | 原文不被翻译覆盖，术语不强制改写；字幕不增加图像查看数或证明成功 |
| 缺失音轨/字幕及坏输入 | 明确 unavailable/error；不自动下载模型、不空造转写 |
| 旧版本迁移 | 31 项原有行为在显式严格模式保持成立；旧结果与原下载技能不变 |
