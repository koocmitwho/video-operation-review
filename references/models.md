# 新模型优化与向下兼容

本技能要求模型支持图像输入，并能通过宿主实际查看证据。**纯文本模型不兼容；明确说明后停止审阅，不提供纯文本降级流程。** 兼容范围由实际能力决定。

## 当前优化基准

以下是 2026-09-25 核对的能力基准，用于决定如何呈现证据。

| 宿主 | 新模型基准 | 对本技能的影响 |
|---|---|---|
| Codex | GPT-6 Astra；同代 GPT-6 Sol / Luna | 用清楚的目标、证据约束和当前操作上下文驱动审阅，详细命令按需读取；避免强制每张图单独长篇复述或机械拆分代理 |
| DeepSeek Harness | DeepSeek-V4.1-Flash，官方 API 名称 `deepseek-flash` | 使用原生视觉核对操作；同时检查 Harness 给该模型声明的图像能力和实际送入模型的图片尺寸 |

OpenAI 当前模型资料与技能建议见 [模型目录](https://developers.openai.com/api/docs/models)、[GPT-6 技能与提示词建议](https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra)。DeepSeek 的版本与图像输入见 [更新日志](https://api-docs.deepseek.com/updates/) 和 [视觉接口](https://api-docs.deepseek.com/guides/vision/)。

## 开始前核对能力

确认当前模型/路由、可用图片工具和本地命令工具；记录可核实的实际值，未知保持未知。已明确是纯文本模型时停止。模型声明支持图片后，实际打开本轮一张证据，确认能看到内容；仅工具返回附件 ID、文字占位符或文件路径不能通过。

DeepSeek 的模型别名与宿主能力目录是两层：官方旧名可能转到新模型，但旧 Harness 的目录仍可能把它声明为纯文本；自定义的新 ID 也不一定已标记为支持图像。以当前路由能力和实际图片结果为准。不要只凭名字含 `vision`、`v4` 或“最新版”判定兼容。

## 图片清晰度优先于一次装入更多帧

先看同一操作区间的全画面定位对象，再并列核对必要的操作前、编辑中、确认后与结果画面。拼图用于粗审；最终数值、单位、勾选状态和临时值/最终值差异用单张图或局部裁剪确认。每次只附带解决当前问题所需的证据。

模型可能支持高分辨率图片，但宿主会先缩放：已检查的 DSH `dsh-llm-deepseek` 0.1.5-rc.3 默认单图像素预算为 640,000，可由 `imagePixelBudget` 修改；这是该适配器的默认值，不是 DeepSeek 模型的永久上限。它还可能把较早图片换成占位符。当前公开 API 文档的图片计量也可能比本地适配器更新。依据实际返回尺寸、占位符和服务端 usage 记录事实。[适配器说明](https://github.com/deepseek-ai/deepseek-harness/tree/master/packages/llm/llm-deepseek)

当 1920×1080 的完整录屏里某个数字太小时，直接从已有证据裁剪参数框，保留字段名、单位和必要上下文，再用宿主图片工具查看；例如：

```text
python scripts/review_video.py crop --work ./work/tutorial --asset f000000024 --box 400,200,1000,600
```

上述帧号和坐标只是示例，实际使用前先从已导出的原图定位。裁剪不会改变源帧身份。Codex 有 `original` 查看选项时可以按需使用；宿主不暴露该选项时，不向工具传入虚构参数，改用可读的局部证据。

## 兼容旧视觉模型

旧视觉模型满足上述能力条件即可沿用全部核心流程；不要求 GPT-6 专属参数、异步工具、结构化输出 API 或子代理能力。默认保留用户选定的模型与推理档位。

- 上下文较小时，以一个有完整前后关系的操作单元为一批，必要时分多轮查看；每批写入步骤、疑点与帧引用，不设置全视频固定抽帧上限。
- 每次输出控制在当前操作的对象、变化、确认/取消、证据和未知项。无法核实的值写 null，继续补看相关证据，不因使用新旧模型而改变证据标准。
- 上下文压缩、任务续接或历史图片被移出后，先读取 `status`、`intervals` 和 `candidates --pending`。重新打开当前待核对步骤所需的图；重新打开不重复增加源帧计数，既有结果仍保留。
- 没有异步/并行能力时顺序执行；没有独立审阅者时保留 self_review 与未通过的复核门禁。

CLI 参数和数据库 v1/v2/v3 的兼容由脚本测试验证。模型语义效果仍需用实际模型试用。
