# 验证说明

本页说明当前版本已经验证的工程行为和仍未证明的范围。源码、技能格式、实际看图和语义正确性是不同层次的证据。

## 脚本与格式

- 共 61 项 unittest：31 项旧模式回归、21 项分层行为、9 项语言与时间对齐检查。
- 已使用真实 FFmpeg 和可控短视频验证索引、解码、抽图及时间映射。
- 技能入口已通过 skill-creator 格式校验；格式通过不等于行为完整。
- 本次发布副本的测试日志与摘要位于 [validation/](../validation/verification.json)。

重测命令（从仓库根目录运行）：

```text
python -X utf8 -m unittest discover -s scripts/tests -v
```

本次发布副本实测环境：Windows、Python 3.10.11、NumPy 2.2.6、Pillow 12.0.0、SQLite 3.40.1、FFmpeg/ffprobe 8.1.2；61 项测试耗时 130.914 秒。此前开发版本另在 Python 3.12.10、NumPy 2.5.1、Pillow 12.3.0、SQLite 3.49.1 下通过 61 项测试。其他系统与版本尚未完成同等验证。

## 覆盖的主要行为

| 类别 | 用例 |
|---|---|
| 视频索引 | 原始 PTS、VFR、非零起点、不同尺寸、H.264 B 帧呈现顺序 |
| 缓存与恢复 | 内容变化拒绝混用、预算暂停恢复、强制中断、提前 EOF、损坏输入 |
| 证据管理 | 原图/裁剪/拼图身份、查看去重、未看证据、缺失/篡改文件、嵌套引用 |
| 严格模式 | 每个连续 RGB 状态说明、参数/对象/文件衔接、确认与结果缺口、旧库迁移 |
| 分层模式 | 全时间线建议、孔洞/重叠、近似与精确合并区分、操作角色、已进行/已完成精审分列 |
| 抽查与复核 | 内容绑定、过期抽查、异常局部展开、缩小范围不能消除异常、复核范围和身份声明 |
| 语言 | SRT/VTT/内嵌文本字幕、中英混合、偏移/重叠、VFR 显示区间、缺失音轨字幕、外部转写时间基准 |

测试里的 `synthetic-test://...` 是明确标识的模拟记账事件，只用来检查脚本约束，不能计为模型实际看图。

## 合成教程的实际视觉试用

使用 32 帧、640×360 的合成 UI 教程，包含等待、鼠标/光标变化、单帧菜单、临时输入、取消、重输、应用和文件交接状态。

| 项目 | 严格模式 | 分层模式 |
|---|---:|---:|
| 全帧计算 | 32/32 | 32/32 |
| 实际显示的不同源帧 | 32 | 18 |
| 预设可见状态检查点 | 9/9 | 9/9 |
| 最终应用值 | 0.02 | 0.02 |
| 该参数的记录错误数 | 0 | 0 |
| 完整审阅门禁 | 未通过，素材有缺口 | 未通过，素材有缺口 |

分层试用有 6 个粗审区间、4 个候选操作单元。粗审覆盖 32 帧；操作精审涉及帧 16–24，共 9 帧范围；因步骤仍有未解决项，“已完成精审”范围为 0。候选分组数不是视频真实操作总数。

看图计数曾通过实际工具返回图片与源 PNG/拼图哈希核对。它能证明图片被工具展示，不能证明模型注意力或语义理解无误；脚本中的 independently_verified_visual_frames 仍保持 null。原始会话日志及逐调用收据作为本地开发审计保存，没有包含在公开仓库中，因此本页属于试用结果摘要，读者可以重跑合成测试和自行复核。

此次独立试用在诊断统计时误搜到测试片段；语义主稿在该搜索前已写出，但仍不能把本次称为严格盲测。素材未展示的菜单入口、准确点击、完整文件路径、文件内容同一性和参数单位均被保留为未知。

18 对 32 仅是这一片段的实际源帧查看数量比较，不表示所有视频都能按同一比例减少工作，也不能据此推断总 token、耗时或费用节省。

## 语言模块验证

语言测试使用可控字幕和合成转写 JSON。没有运行真实 ASR、OCR 或自动翻译后端；没有语音识别准确率结论。字幕与已有转写可以提供操作线索，但不能通过视觉参数或点击证据检查。

## 已知限制

- 未完成真实用户软件录屏的系统性验收，也没有独立标注的大规模基准。
- 变化分段与有限抽查可能遗漏未抽中的细节；压缩、低清和遮挡会进一步限制识别。
- 首次扫描、源文件哈希、全尺寸差分与恢复回放都有成本，长视频吞吐和内存尚未全面测量。
- 数据库按单写入者使用；多代理应分别产出记录，再串行导入。
- 多视频流、特殊色彩/高位深、动态分辨率以及其他平台组合没有全面覆盖。

后续验收标准见 [layered-acceptance.md](layered-acceptance.md)；脚本约束通过不能被替换成“操作已经完整理解”的结论。
