全量 intervals/validate JSON 曾超出宿主输出预算；代理将完整输出落盘，再读取摘要后继续。该处理已写入 [交付指引](delivery.md)。单次代理试用耗时包括读取指引、看图、判断、登记、等待与恢复，不能外推长视频性能。

此前 97 项回归分别在 Windows / Python 3.12.10 和 3.10.11 下通过，耗时 105.291 与 171.876 秒，两套并行运行。

- 角色证据按原图/裁剪的实际覆盖区域核对，严格与分层共用调用关联检查。
